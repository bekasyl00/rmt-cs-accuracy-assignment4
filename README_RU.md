## Как проверить работу

Распакуйте `Assignment4_Updated_Package.zip`, откройте Terminal в папке `Assignment4_Project` и выполните:

```bash
python3 reproduce_all.py --verify
```

Нужен Python 3.12 или новее. Устанавливать пакеты, скачивать модель и входить в аккаунты не требуется. Команда пересчитывает таблицы, статистику и графики из сохранённых ответов и оценок. Успешный результат заканчивается строкой `PASS: 22 CSV/SVG files match saved evidence`.

## Что открыть

| Файл или папка | Назначение |
|---|---|
| `Assignment4_Report.docx` | Итоговый отчёт для сдачи |
| `reproduce_all.py` | Единственная команда полной проверки |
| `data/` | Исходные данные Assignment 3 |
| `analysis/` | Расчёты и графики по исходным данным |
| `results/`, `diagnostics/`, `audit/` | Исходные таблицы, проверки устойчивости и проверка отдельных записей |
| `supplement/` | Все данные, расчёты и графики нового дополнительного эксперимента |
| `docs/` | Пояснения для защиты, запись воспроизведения и инструкция нового запуска модели |
| `logs/` | Сохранённые журналы программных проверок |
| `archive/` | Инструкция первоначального релиза для сохранения происхождения работы |

Описание каждого основного скрипта и результирующего файла: `docs/file_guide_ru.md`.

Новый запуск ИИ — отдельная необязательная операция, описанная в `docs/fresh_generation.md`. Для сдачи и проверки существующих результатов он не нужен. Папка `reproduced/` создаётся автоматически при проверке; её можно удалить и создать повторно той же командой.

Ранее Bekasyl подтвердил успешное выполнение полной проверки 22 файлов. Этот факт записан в `docs/reproduction_record.json`; он не является независимым человеческим переоцениванием правильности ответов.
